# 💳 Bank Account Simulator

A simple console-based **Bank Account Simulator** built using Java. This project allows users to create a bank account and perform basic banking operations through an interactive menu.

## 🚀 Features

* Create a bank account
* Check account balance
* Deposit money
* Withdraw money
* Prevent withdrawals greater than the available balance
* Validate invalid deposit and withdrawal amounts
* Display account details
* Interactive command-line menu

## 🛠️ Technologies Used

* **Java**
* **Java OOP**
* **Scanner** for user input

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project folder

```bash
cd bank-account-simulator
```

### 3. Compile the Java files

```bash
javac BankAccount.java Main.java
```

### 4. Run the program

```bash
java Main
```
